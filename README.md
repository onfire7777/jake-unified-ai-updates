# Jake Unified AI updates

This public repository hosts signed desktop installers and updater files for Jake Unified AI. The application source remains in a separate private repository.

A release is published only after its Windows, macOS, and Linux installers, Tauri updater signatures, and installed-update checks have been qualified. The `latest.json` feed and versioned release assets are consumed automatically by installed Jake Unified AI builds; users do not need a GitHub token or release settings.

There is no production release yet. An empty release list is intentional until qualification is complete.
